## 6. Known open risks

1. Localization table patch is in-memory: any Addressables-driven table reload between locale-change events could momentarily show English until the next re-apply (re-apply hooks: locale change + scene load).
2. `TMP_Settings.fallbackFontAssets` serialized content (whether Noto SC is already listed) is not string-verifiable from disk — resolved at runtime by ChineseFontProvider with a glyph probe.
3. ItemInfoUI / BigMessageUI direct-write strings not yet in the `direct` dictionary — the missing-translation scanner (`LocalizationDebugLog`) collects them at runtime.
4. Harmony `PatchAll` now also patches `TMP_Text.set_text` (TextInterceptor) — always installed, no-op unless localization enabled.
